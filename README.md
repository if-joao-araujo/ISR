# 🌐 Interconexão de Redes (ISR)

Repositório dedicado aos laboratórios práticos, revisões, avaliações e projetos desenvolvidos na disciplina de **Interconexão de Redes** (IFPE — Campus Igarassu), utilizando o **Cisco Packet Tracer**.

## 📂 Módulos e Pastas

| Pasta | Conteúdo |
| :--- | :--- |
| [`01-revisao-roteamento-estatico-vlan`](./01-revisao-roteamento-estatico-vlan) | Revisão de rotas estáticas, VLANs e enlaces Trunk (802.1Q) |
| [`02-boas-praticas`](./02-boas-praticas) | Hardening inicial, acesso remoto via SSH, criptografia de senhas e bloqueio de interfaces |
| [`02-z-primeira-avaliacao`](./02-z-primeira-avaliacao) | Primeira avaliação prática da disciplina |
| [`03-spanning-tree-stp`](./03-spanning-tree-stp) | Prevenção de loops na Camada 2, definição de Root Bridge e Rapid-PVST |
| [`04-switch-camada-3-intervlan`](./04-switch-camada-3-intervlan) | Roteamento Inter-VLAN com Switch Multilayer (SVIs e `ip routing`) |
| [`05-roteamento-dinamico-rip`](./05-roteamento-dinamico-rip) | Roteamento dinâmico vetor de distância com RIPv2 |
| [`06-roteamento-dinamico-ospf`](./06-roteamento-dinamico-ospf) | Roteamento dinâmico link-state com OSPF |
| [`07-roteamento-dinamico-eigrp`](./07-roteamento-dinamico-eigrp) | Roteamento dinâmico avançado com EIGRP |
| [`07-z-segunda-avaliacao`](./07-z-segunda-avaliacao) | Segunda avaliação prática da disciplina |
| [`8-servicos-rede-dhcp-http-dns`](./8-servicos-rede-dhcp-http-dns) | Configuração de servidores de aplicação (DHCP, HTTP e DNS) |
| [`09-projeto-final`](./09-projeto-final) | Projeto integrador unindo Camada 2, Camada 3 e Serviços |

## 📁 Organização Interna das Pastas
Cada pasta segue uma estrutura padrão para consulta e prática:
* `nao-configurada/` — Arquivo `.pkt` inicial para praticar do zero.
* `configurada/` — Arquivo `.pkt` finalizado e testado.
* `topologia.png` — Imagem da topologia do cenário.
* `README.md` — Resumo teórico e tutorial passo a passo de configuração.
